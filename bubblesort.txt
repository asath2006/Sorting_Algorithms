If you're asking what happens with a pair like 1 and 2 during bubble sort:

Suppose the list is:

1 -> 2 -> 5

At some iteration:

curr     -> 1
nextNode -> 2

The condition is:

if(curr->data > nextNode->data)

which becomes:

if(1 > 2)

This is false.

So no swap occurs.

The code executes the else part:

prev = curr;
curr = curr->next;

Now:

prev -> 1
curr -> 2

List remains:

1 -> 2 -> 5

Then the next comparison is:

2 and 5

Again:

if(2 > 5)

False, so no swap.

Rule
If left value > right value ? swap nodes.
If left value = right value ? leave them as they are and move forward.

Examples:

5 -> 3   => swap

becomes

3 -> 5

but

1 -> 2   => no swap

stays

1 -> 2

because it's already in sorted order.
